# 原理图检查表

## ESP32-S3 部分

- EN 引脚有正确上拉和复位电路。
- GPIO0 有 BOOT 按键，不会在正常启动时被错误拉低。
- USB D+ / D- 分别接 GPIO20 / GPIO19。
- GPIO0、GPIO3、GPIO45、GPIO46 没有被外部电路拉成错误启动状态。
- R8 模组可能被 PSRAM 占用的引脚没有拿去接外设。

## OV3660 部分

- AVDD 使用 2.8V 干净模拟电源。
- DOVDD 使用 1.8V，除非你明确设计了其他电平方案。
- SCCB 上拉电阻接到 DOVDD。
- RESETB 和 PWDN 都接到 ESP32-S3 GPIO。
- PWDN 有明确默认状态，不能悬空。
- DVP 使用 D9..D2 作为 8 位数据。
- D1/D0 第一版不接。
- XVCLK、PCLK、VSYNC、HREF 都有连接和测试点。

## 电源和保护

- USB-C CC 电阻已经放置。
- 3.3V 稳压器电流能力能覆盖 Wi-Fi 峰值。
- 舵机 5V 电源路径有足够线宽和大电容。
- 每一路电源都有测试点。
- 如果加入备用电池，不能只画一半电路，必须完整包含充电、保护和温度安全设计。

## PCB 版图

- 摄像头去耦电容靠近摄像头接口或传感器。
- ESP32-S3 天线禁布区符合数据手册。
- 摄像头 DVP 走线尽量短，并尽量长度接近。
- 大电流舵机走线不要从摄像头模拟电源附近经过。
