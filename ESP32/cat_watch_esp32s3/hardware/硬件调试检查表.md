# 硬件调试检查表

## 上电前检查

- 检查 USB-C 5V 输入是否短路。
- 检查 3.3V、2.8V、1.8V、5V_SERVO 是否对地短路。
- 检查 ESP32-S3 模组天线禁布区是否干净。
- 检查 OV3660 排线座方向和 1 脚位置。
- 检查 BOOT 和 RESET 按键是否能正常按下。

## 第一次上电

- 用限流电源或带保护的 USB 电流表上电。
- 不接舵机时先测 5V_IN、3V3、2V8、1V8。
- 上电 5 分钟后摸测或测温，确认稳压芯片不过热。

## ESP32-S3 调试

- 确认 USB Serial/JTAG 能识别。
- 烧录最简单的日志或闪灯程序。
- 确认 PSRAM 能被识别。
- 确认 Wi-Fi 能连接并保持 30 分钟不断线。

## 摄像头调试

- 上电时先让 OV3660 处于复位或掉电控制状态。
- 确认 SCCB 上拉电压和 DOVDD 一致。
- 读取摄像头 ID。
- 采集 QVGA JPEG 图像。
- 在接模型前先连续推流 2 小时。

## 舵机调试

- 舵机先用外部 5V 测试。
- 确认舵机动作时 ESP32-S3 不重启。
- 如果舵机动作导致 Wi-Fi 掉线，需要增加电容或改电源走线。
