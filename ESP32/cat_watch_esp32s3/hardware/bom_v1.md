# 第一版 BOM 选型建议

这不是最终采购清单，而是画原理图时需要确定的器件类别。

## 核心器件

| 器件 | 推荐 | 原因 |
| --- | --- | --- |
| ESP32-S3 模组 | ESP32-S3-WROOM-1-N16R8 | 8MB PSRAM + 16MB Flash，适合摄像头和 AI |
| ESP32-S3 备选模组 | ESP32-S3-WROOM-1U-N16R8 | 外壳遮挡天线时使用外接天线 |
| 摄像头 | OV3660 模块或匹配排线的裸传感器方案 | DVP + SCCB，适合 ESP32-S3 |
| 摄像头座 | 和所选 OV3660 模块排线匹配 | 必须确认间距和 1 脚方向 |

## 电源器件

| 电源 | 器件类型 | 说明 |
| --- | --- | --- |
| 5V_IN | USB-C 座 + 保护器件 | USB-C Sink 需要 CC 电阻 |
| 3V3 | 降压芯片或大电流 LDO | 要覆盖 ESP32-S3 Wi-Fi 峰值电流 |
| 2V8_AVDD | 低噪声 LDO | 摄像头模拟电源 |
| 1V8_DOVDD | LDO | 摄像头 I/O 电源 |
| 5V_SERVO | 带保护的 5V 分支 | 舵机接口附近加大电容 |

## 调试和扩展

| 项目 | 建议 |
| --- | --- |
| USB | ESP32-S3 原生 USB，接 GPIO19/GPIO20 |
| 按键 | BOOT 和 RESET |
| 测试点 | 5V、3V3、2V8、1V8、GND、EN、BOOT、SIOC、SIOD、PCLK、VSYNC |
| 舵机接口 | 5V_SERVO、GND、PWM 三针 |
| 音频接口 | 预留 I2S 麦克风和 I2S 功放焊盘 |
| 存储 | 如果板子空间允许，预留 microSD |

## PCB 默认建议

- 第一版建议 4 层板：信号层、地层、电源层、信号层。
- 摄像头 DVP 走线下面尽量有完整地参考。
- ESP32-S3 天线禁布区不能放铜皮、器件、电池或金属外壳。
- 舵机电源走线远离摄像头模拟电源和 ESP32-S3 3.3V 主电源。
