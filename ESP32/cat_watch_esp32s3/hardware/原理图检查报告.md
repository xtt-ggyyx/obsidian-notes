## 二、严重问题（必须修正）

### 2.1 模组型号错误 — PSRAM 不足

**当前：ESP32-S3-WROOM-1-N8R2（8MB Flash + 2MB PSRAM）**

根据 ESP32-S3 数据手册表 1（Page 3）：

| 型号 | PSRAM | Flash | 温度等级 |
|------|-------|-------|----------|
| N8R2 | 2MB (Quad SPI) | 8MB | 40~105°C |
| **N16R8** | **8MB (Octal SPI)** | **16MB** | **40~65°C** |
| N8R8 | 8MB (Octal SPI) | 8MB | 40~65°C |

**问题：**
- 你的项目需要 OV3660 摄像头 + AI 猫检测模型
- OV3660 3MP 图像缓冲需要大量 PSRAM
- esp32-camera 组件：除 CIF 或更低分辨率 JPEG 外，基本需要 PSRAM
- AI 模型推理（TinyML / TFLite）也需要大量内存
- 2MB PSRAM 完全不够用

**建议：更换为 ESP32-S3-WROOM-1-N16R8（16MB Flash + 8MB PSRAM）**

> 注意：N16R8 温度等级为 40~65°C，如果你的设备在户外高温环境使用，需要考虑散热。

### 2.3 电源设计严重不完整

#### OV3660 电源需求（数据手册 Page 3）

| 电源 | 电压范围 | 典型值 | 描述 |
|------|----------|--------|------|
| **AVDD** | 2.6 ~ 3.0V | **2.8V** | 模拟电源（需要干净） |
| **DOVDD** | 1.7 ~ 3.0V | **1.8V（推荐）** | I/O 电源（需要干净） |
| **DVDD** | 1.5V ±5% | 1.5V | 数字核心电源（可用内部 LDO） |

#### 当前原理图状态

| 电源轨 | 状态 | 说明 |
|--------|------|------|
| 5V_IN | ✅ 已画 | USB-C 输入 |
| 3.3V | ✅ 已画 | SGM2212-3.3, 800mA |
| **2.8V (AVDD)** | ❌ **未确认** | **OV3660 模拟电源，必须补** |
| **1.8V (DOVDD)** | ❌ **未确认** | **OV3660 I/O 电源，必须补** |
| 1.5V (DVDD) | ⚠️ 可用内部 | OV3660 内置 1.5V LDO，推荐使用内部 |

**建议方案：**
- 添加一个 2.8V LDO（如 SGM2212-2.8 或同类），从 5V 降压，给 AVDD
- 添加一个 1.8V LDO（如 SGM2212-1.8 或同类），从 5V 降压，给 DOVDD
- DVDD 使用 OV3660 内部 LDO（推荐，因为 DOVDD=1.8V 时内部压降小）
- 每路电源都要有去耦电容（参考设计用 0.1μF-0201），靠近传感器引脚

## 三、需要确认的问题

### 3.1 USB 数据线连接

Type-C 有正反插两组 USB 2.0 数据脚：

| Type-C Pin | 信号 | 应连接到 |
|------------|------|----------|
| A6 | D+ (DP1) | 合并 → GPIO20 (USB_D+) |
| B6 | D+ (DP2) | 合并 → GPIO20 (USB_D+) |
| A7 | D- (DN1) | 合并 → GPIO19 (USB_D-) |
| B7 | D- (DN2) | 合并 → GPIO19 (USB_D-) |

**检查项：**
- [ ] DP1 和 DP2 是否已合并
- [ ] DN1 和 DN2 是否已合并
- [ ] 合并后 D+ 接 GPIO20
- [ ] 合并后 D- 接 GPIO19
- [ ] 建议预留 22Ω 或 33Ω 串联电阻，靠近 ESP32-S3

### 3.2 ESP32-S3 基础电路

#### 引脚分配确认（数据手册 Page 9-10）

| Pin# | 名称 | 功能 | 检查项 |
|------|------|------|--------|
| 1 | GND | 地 | 必须接地 |
| 2 | 3V3 | 电源 | 接 3.3V |
| 3 | EN (CHIP_PU) | 复位 | 10kΩ 上拉 + 1μF + 复位按键 |
| 4 | IO4 | GPIO4 | 可用 |
| 5 | IO5 | GPIO5 | 可用 |
| 6-7 | IO6-IO7 | GPIO6-7 | 可用 |
| 8-9 | IO15-IO16 | GPIO15-16 | 可用 |
| 10-11 | IO17-IO18 | U1TXD/U1RXD | 可用作串口 |
| 12 | IO8 | GPIO8 | 可用 |
| **13** | **IO19** | **USB_D-** | **接 USB D-** |
| **14** | **IO20** | **USB_D+** | **接 USB D+** |
| 15 | IO3 | GPIO3 | Strapping 引脚 |
| 16 | IO46 | GPIO46 | Strapping 引脚 |
| 36 | RXD0 | U0RXD/GPIO44 | 调试串口接收 |
| 37 | TXD0 | U0TXD/GPIO43 | 调试串口发送 |
| 40 | GND | 地 | 必须接地 |
| 41 | EPAD | 散热地 | **必须接地，加过孔** |

#### Strapping 引脚（数据手册 Page 10-11）

| 引脚 | 功能 | 默认状态 | 注意事项 |
|------|------|----------|----------|
| **GPIO0** | Strapping | 上拉=1 | 决定启动模式；IO0 BOOT 按键 |
| **GPIO3** | Strapping | 串口下载 | 影响JTAG/USB JTAG |
| **GPIO45** | Strapping/VDD_SPI | 上拉=1 | **N8R2: VDD_SPI 由 eFuse 控制** |
| **GPIO46** | Strapping | 上拉=1 | 配合 GPIO0 决定启动电压 |

**关键：**
- GPIO46 = 1 且 GPIO0 = 0 会进入下载模式
- VDD_SPI 在 N8R2 上由 eFuse 控制（EFUSE_VDD_SPI_FORCE=1, EFUSE_VDD_SPI_TIEH=1 → 3.3V）
- GPIO45 在 N8R2 上不影响 VDD_SPI

### 3.3 CHIP_PU (EN) 电路

数据手册参考设计（Page 24）：
- R = 10kΩ 上拉到 3.3V
- C = 1μF 到 GND
- 复位按键到 GND

**检查：**
- [ ] 电容是 1μF，不是 100nF
- [ ] 复位按键按下时拉低 CHIP_PU
- [ ] CHIP_PU 走线尽量短

### 3.4 3.3V LDO 电流余量

SGM2212-3.3 参数：
- 最大输出电流：800mA
- 压降：450~610mV @ 800mA
- PSRR：80dB @ 120Hz

ESP32-S3 Wi-Fi 峰值电流约 300-400mA，加上摄像头和其他外设，800mA 应该够用，但余量不大。

**建议：**
- 摄像头不要共用 3.3V（用独立的 2.8V 和 1.8V）
- 舵机必须独立 5V 供电
- 如果后续加音频/SD卡，考虑换成 DCDC 或更高电流 LDO

## 四、OV3660 上电时序要求（数据手册 Page 26-27）

### 使用内部 DVDD（推荐，因为 DOVDD=1.8V）

```
DOVDD ──────┐              ┌──────────────────
            │              │
AVDD  ──────┼──────────────┼──────────────────
            │   t0 ≥ 0ms   │
PWDN  ──┐   │              │   ┌──────────────
        │   │              │   │
        └───┼──────────────┼───┼──────────────
            │              │   │
XVCLK  ────┼──────────────┼───┼──────────────
            │              │   │
RESETB ────┼──────────────┼───┼──┐────────────
            │              │   │  │
SCCB   ────┼──────────────┼───┼──┼────────────
            │              │t2≥5ms│t3≥1ms│t4≥20ms
```

**关键时序要求：**
1. DOVDD 先上电，AVDD 紧随其后（t0 ≥ 0ms）
2. PWDN 在上电期间必须为高
3. AVDD 稳定后至少 5ms 才能拉低 PWDN（t2 ≥ 5ms）
4. PWDN 拉低后至少 1ms 才能拉高 RESETB（t3 ≥ 1ms）
5. RESETB 拉高后至少 20ms 才能访问 SCCB（t4 ≥ 20ms）
6. XVCLK 在 SCCB 访问前至少 2ms

**注意：PWDN 不能悬空！** 数据手册明确标注。

## 五、PCB Layout 注意事项

### 5.1 ESP32-S3-WROOM-1 天线禁布区（数据手册 Page 26）

```
天线区域约 15mm 禁布区
所有层禁止：铺铜、走线、放器件
```

- 模组尺寸：18 × 25.5 × 3.1 mm
- 天线在模组一端，约 7.5mm 区域
- 禁布区从天线端延伸约 15mm
- EPAD 必须接地，加过孔散热

### 5.2 OV3660 布局要求

- AGND 和 DGND 应分开，在模块外单点连接
- 去耦电容尽量靠近传感器引脚
- 如果空间允许，DVDD 和 DGND 之间加 1μF-0402 电容
