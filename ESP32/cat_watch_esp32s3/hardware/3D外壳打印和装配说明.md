# 3D 外壳打印和装配说明

## 需要的软件

推荐使用 OpenSCAD。

原因：

- 文件是纯文本，适合放进 GitHub。
- 参数容易修改。
- 换电脑后只要重新安装 OpenSCAD 就能继续改。
- PCB 尺寸变化后，不需要重新从零建模。

## 文件位置

外壳源文件：

```text
hardware/case_parametric.scad
```

可直接打开查看的预览文件：

```text
hardware/enclosure_preview/cat_watch_enclosure_offline_preview.html
hardware/enclosure_preview/cat_watch_enclosure_preview.html
hardware/enclosure_preview/cat_watch_enclosure_preview.obj
hardware/enclosure_preview/cat_watch_enclosure_preview.stl
```

其中 `offline_preview.html` 不需要联网，直接双击就能看简化外观。
`preview.html` 是可旋转 3D 预览，需要浏览器能加载 Three.js。
`obj` 和 `stl` 可以用 3D 查看器、切片软件或建模软件打开。

设计说明：

```text
hardware/case_design.md
```

## 导出 STL

当前仓库里已经生成了一个结构预览 STL：

```text
hardware/enclosure_preview/cat_watch_enclosure_preview.stl
```

这个 STL 是预览模型，适合先看外观，不建议直接作为最终打印件。
最终打印建议从 OpenSCAD 参数化文件导出。

1. 打开 OpenSCAD。
2. 打开 `hardware/case_parametric.scad`。
3. 修改顶部的 `preview_part`。
4. 按 F6 渲染。
5. 导出 STL。

可选零件：

```text
preview_part = "body";        // 主壳体
preview_part = "lid";         // 底盖
preview_part = "servo_base";  // 舵机底座
preview_part = "all";         // 总览，不建议直接打印
```

## 需要根据 PCB 修改的参数

如果 PCB 尺寸变化，优先改这些：

```scad
pcb_w = 70;
pcb_d = 50;
inner_h = 24;
```

如果摄像头位置变化，改这些：

```scad
camera_hole_d = 14;
camera_center_x = 0;
camera_center_z = 18;
```

如果 USB-C 位置变化，改这些：

```scad
usb_w = 12;
usb_h = 7;
usb_center_x = 0;
usb_center_z = 9;
```

## 打印参数建议

- 材料：PLA 或 PETG。
- 层高：0.2 mm。
- 壁线：3 圈。
- 填充：15% 到 25%。
- 主壳体：开口朝下打印。
- 底盖：平放打印。
- 舵机底座：平放打印。

## 装配顺序

1. 先把 PCB 固定到底盖或壳体螺丝柱。
2. 确认摄像头正对前方开孔。
3. 插上 USB-C，确认后部开孔不干涉。
4. 合上底盖。
5. 如果使用舵机，把舵机装入舵机底座。
6. 把主壳体固定到舵机转盘或十字臂上。
7. 测试舵机左右转动是否拉扯 USB 线和摄像头排线。

## 第一版容易出问题的地方

- 摄像头孔太小，导致画面被遮挡。
- USB-C 开孔偏移，导致线插不进去。
- 螺丝柱和 PCB 元件冲突。
- ESP32-S3 天线区域被螺丝柱或金属遮挡。
- 舵机转动时 USB 线被拉扯。
- 壳体太密闭，长时间运行温度偏高。

## 建议的迭代方式

第一版不要追求完美外观。

建议先打印一个低成本版本：

- 壁厚正常。
- 填充低一点。
- 只验证孔位、安装和散热。

确认 PCB、摄像头、USB-C、舵机都没有干涉后，再优化外观。
