# 项目优化建议

这份文档是对当前项目方案的整体复查，重点看哪些地方会影响后续能不能顺利做出可用原型。

## 最值得优先优化的地方

### 1. 先确定 PCB 外形和固定孔，再细化外壳

当前外壳已经有参数化初版，但 PCB 还没有最终尺寸。

建议先确定：

- PCB 长宽。
- 4 个安装孔位置。
- 摄像头模块位置。
- USB-C 位置。
- ESP32-S3 天线位置。
- 舵机是否一定要装在底部。

这些确定后，外壳参数才能从“概念外壳”变成“能装配外壳”。

### 2. 摄像头最好独立成小板或靠近外壳前面

OV3660 位置会直接影响视角。

如果摄像头跟主板在同一块 PCB 上：

- 外壳开孔必须精准。
- PCB 安装误差会影响摄像头居中。
- 后期调整视角不方便。

更推荐：

- 主控 PCB 放在外壳内部。
- 摄像头模块用短排线连接，固定在外壳前面。

这样外壳和视角更容易调。

### 3. 舵机建议控制整个外壳水平旋转

不要第一版就做云台式双轴结构。

第一版建议：

- 只做水平左右旋转。
- 舵机放在底座。
- 整个外壳固定在舵机转盘上。

这样机械结构简单，也方便排查问题。

### 4. 电源设计要比功能设计更保守

这个项目同时有 Wi-Fi、摄像头、AI 推理和舵机。

最容易出问题的是：

- 舵机一动，ESP32-S3 重启。
- 摄像头画面有噪声。
- Wi-Fi 高峰电流导致 3.3V 掉压。

建议：

- 舵机 5V 单独走线。
- 3.3V 稳压器电流余量留足。
- 摄像头 2.8V 模拟电源用低噪声 LDO。
- 每一路电源都放测试点。

### 5. 模型接入不要和硬件调试混在一起

第一块 PCB 回来后，先不要急着跑猫检测模型。

顺序应该是：

1. 电源稳定。
2. ESP32-S3 能下载。
3. PSRAM 能识别。
4. Wi-Fi 稳定。
5. 摄像头能出图。
6. 网页能看视频。
7. 再接模型。

这样出问题时能知道问题在哪一层。

## 固件可以优化的地方

### 1. HTTP 接口解析 JSON 目前比较简单

当前 `/api/regions` 用的是简单字符串解析。

优点是代码简单。
缺点是以后字段复杂后容易出错。

后续建议：

- 接入 ESP-IDF 自带或常用 JSON 解析库。
- 对区域坐标做范围检查。
- 防止用户传入负数或超出画面大小。

### 2. 摄像头和模型最好分两个帧率

视频流和 AI 检测不需要同样帧率。

建议：

- 视频流：尽量流畅，例如 8 到 15 FPS。
- 猫检测：低频运行，例如 1 到 3 FPS。

行为判断不需要高帧率，降低检测频率可以减少发热和卡顿。

### 3. 行为判断需要加入“防抖”

当前行为判断已经有基础状态机。

后续可以优化：

- 连续 N 次检测到猫才认为出现。
- 连续 N 次漏检才认为消失。
- 区域判断用检测框面积重叠比例，不只看中心点。
- 左右离开判断加入移动方向，而不是只看边缘消失。

### 4. 事件记录最好加时间来源

当前事件时间是设备启动后的毫秒数。

后续建议：

- Wi-Fi 连上后用 SNTP 对时。
- 事件记录真实日期和时间。
- 手机网页显示“今天 14:30 吃饭 62 秒”。

## PCB 可以优化的地方

### 1. 第一版不要做得太小

你现在是学习和自研 PCB 阶段。

第一版 PCB 建议：

- 大一点。
- 测试点多一点。
- 接口好焊一点。
- 电源和摄像头走线宽松一点。

先成功，再缩小。

### 2. 推荐预留但不一定焊接的接口

建议预留：

- I2S 麦克风。
- I2S 功放。
- 舵机接口。
- microSD。
- UART 调试口。
- 摄像头关键引脚测试点。

第一版可以不焊音频和 microSD，但焊盘留着。

### 3. 如果用 WROOM-1，外壳要避开天线

如果使用 PCB 天线版本：

- 外壳前后要让天线靠边。
- 天线附近不能放舵机金属螺丝。
- 天线区域不要被电池挡住。

如果空间不好安排，直接用 WROOM-1U 外接天线更稳。

## 外壳可以优化的地方

### 1. 外壳前面建议做轻微倾角

猫咪通常在地面或低处活动。

如果摄像头放桌面上，水平看可能拍不到地面近处。

建议外壳或底座预留：

- 5 到 10 度向下倾角。
- 或者用支架调节角度。

当前 3D 预览先做直立款，后续可加倾角底座。

### 2. 后部 USB 线要留转动空间

如果舵机带动整机转动，USB 线会被拉扯。

建议：

- 舵机旋转角度限制在 30 到 60 度范围。
- USB 线从后方中间出来。
- 软件里限制舵机角度，不允许 0 到 180 全范围乱转。

### 3. 散热孔要避开猫毛和灰尘堆积

顶部散热有效，但也容易进灰。

建议：

- 顶部开长条散热孔。
- 侧面也开少量散热孔。
- 底部不要完全密闭。
- 外壳内部不要压住 ESP32-S3 模组。

## 远程访问建议

第一版只做局域网是正确的。

后续低成本远程访问优先顺序：

1. 家里有公网 IPv6：优先 IPv6 + 防火墙 + 认证。
2. 有公网 IPv4：DDNS + 端口转发 + 认证。
3. 没有公网：再考虑最低配置云服务器中转。
4. 视频尽量不要 24 小时上传云端，只上传事件截图或低帧率预览。

## 当前最推荐的下一步

1. 先确认 PCB 尺寸和摄像头模块形式。
2. 根据尺寸修改 `hardware/case_parametric.scad`。
3. 打印一个外壳小样，只验证孔位和装配。
4. 同时开始画原理图。
5. 原理图完成后，把引脚和外壳再统一检查一次。
