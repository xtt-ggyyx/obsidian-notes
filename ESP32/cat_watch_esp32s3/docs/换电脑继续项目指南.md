# 换电脑继续项目指南

## 核心原则

想要换电脑后无缝衔接，关键是把项目资料都放进 GitHub，并且把软件环境记录清楚。

这个项目现在已经放在你的 Obsidian GitHub 仓库里：

```text
ESP32/cat_watch_esp32s3
```

以后换电脑时，只要把这个仓库 clone 下来，就能拿到：

- 中文项目计划。
- 固件工程。
- 硬件设计资料。
- 3D 外壳 OpenSCAD 文件。
- 进度总表。

## 新电脑需要安装的软件

### 1. Git 和 GitHub Desktop

用途：

- 拉取 GitHub 仓库。
- 提交项目进度。
- 在不同电脑之间同步。

建议：

- 安装 Git。
- 安装 GitHub Desktop。
- 登录你的 GitHub 账号。
- Clone `obsidian-notes` 仓库。

### 2. Obsidian

用途：

- 查看中文项目计划和进度总表。
- 写调试记录。
- 管理 PCB、固件、外壳的笔记。

新电脑操作：

1. 安装 Obsidian。
2. 打开本地 clone 下来的仓库文件夹。
3. 找到 `ESP32/cat_watch_esp32s3/项目进度总表.md`。

### 3. ESP-IDF

用途：

- 编译 ESP32-S3 固件。
- 烧录程序。
- 查看串口日志。

建议安装：

- ESP-IDF 官方 Windows 安装器。
- 版本优先跟随 ESP-Detection 官方示例要求。

安装后进入：

```powershell
cd ESP32/cat_watch_esp32s3/firmware
idf.py set-target esp32s3
idf.py menuconfig
idf.py build
```

### 4. OpenSCAD

用途：

- 打开参数化 3D 外壳文件。
- 修改尺寸。
- 导出 STL。

项目文件：

```text
hardware/case_parametric.scad
```

### 5. PCB 软件

你可以选择 KiCad、嘉立创 EDA 或 Altium。

建议：

- 如果你想方便同步和开源，优先 KiCad。
- 如果你主要在国内打样，嘉立创 EDA 会更方便。
- 不管用哪个软件，都要把工程源文件放进 GitHub 仓库。

推荐目录：

```text
hardware/pcb_project/
```

## 每次换电脑前要做什么

在旧电脑上：

```powershell
git status
git add ESP32/cat_watch_esp32s3
git commit -m "Update cat watch project"
git push
```

确认 GitHub 上能看到最新文件后，再换电脑。

## 在新电脑上恢复项目

1. Clone 你的 Obsidian 仓库。
2. 用 Obsidian 打开仓库。
3. 打开 `ESP32/cat_watch_esp32s3/项目进度总表.md`。
4. 安装 ESP-IDF。
5. 安装 OpenSCAD。
6. 安装 PCB 软件。
7. 从进度总表继续勾选任务。

## 不建议同步的内容

这些文件通常不建议提交到 GitHub：

- ESP-IDF 编译生成的 `build/` 文件夹。
- 临时 `.exe` 测试文件。
- PCB 软件自动备份文件。
- 3D 打印切片软件生成的临时文件。
- Wi-Fi 密码、GitHub token、私钥。

## 建议提交的内容

这些内容应该提交：

- `.c`、`.h`、`.md`、`.scad` 源文件。
- PCB 原理图源文件。
- PCB 版图源文件。
- 关键测试记录。
- 外壳参数文件。
- 重要截图或装配照片。

## 个人工作习惯建议

每完成一个小阶段就提交一次：

- 完成原理图，提交一次。
- 完成 PCB，提交一次。
- 第一次点亮板子，提交一次。
- 摄像头出图，提交一次。
- 网页能打开，提交一次。
- 模型跑通，提交一次。
- 外壳第一版能装配，提交一次。

这样换电脑或回退版本时不会丢进度。
