Obsidian Git 管理工具使用说明

启动：
1. 双击“启动-ObsidianGit管理器.cmd”。
2. 弹出管理员授权时点“是”。

换电脑：
1. 复制整个 scripts 文件夹，不要只复制 ps1。
2. 打开工具后重新选择 Obsidian 仓库路径并保存。
3. 如果要延续 TokenX24 别名编号，保留 tokenx24-counter.txt。
4. 如果要保留已注册账号记录，保留 tokenx24-accounts.txt。
5. 点“一键安装所有同步任务”重新安装计划任务。

TokenX24 起始编号：
“下次编号 +” 表示下一次注册会用的 Gmail 别名编号。
例如填 100 后点“设为起点”，下一次注册就是 +100。

注意：
obsidian-config.json 和 tokenx24-accounts.txt 里包含账号/密码信息，不要发给别人。
